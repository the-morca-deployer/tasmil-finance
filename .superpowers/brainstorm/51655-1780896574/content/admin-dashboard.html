Nội dung từng Tab

Tab 2: Waitlist Entries
• Filter theo status (PENDING / CONFIRMED / ACCESS_SENT)
• Search wallet/email
• Table: wallet, email, queue rank, referrals, joined date
• Inline "Issue Code" → modal tạo code + gửi email ngay
• Bulk select → batch issue
Tab 3: Access Codes
• 3 panels: Individual · Shared (group) · Batch
• Individual: chọn waitlist entry → 1 code → gửi email
• Shared: label + max uses → 1 code dùng nhiều người
• Batch: nhập số lượng → N codes → export CSV hoặc send email
• Table: tất cả codes, status, uses/max, revoke
Tab 4: Email Campaigns
• Tạo campaign: target (all CONFIRMED / top N referrers / specific list)
• Preview email template trước khi gửi
• Status: PENDING → RUNNING → COMPLETED
• Log: targeted / sent / failed / skipped
• Dùng CampaignRun model đã có sẵn
User: Redeem Access Code
• Screen 3 (waitlist status) thêm field "Enter Access Code"
• POST /waitlist/redeem: validate → increment uses → set cookie
• Middleware check cookie tasmil_access → bypass vào app
• Code EXHAUSTED khi hết max uses
