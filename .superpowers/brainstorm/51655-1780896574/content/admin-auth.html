Design Section 2: Admin Authentication

Wallet + PIN → JWT — flow chi tiết

Login Flow (2 bước)

BƯỚC 1 — WALLET CHALLENGE
Frontend gọi POST /admin/auth/challenge
Body: { walletAddress }
→ Backend trả { nonce, expiresAt }

Frontend yêu cầu Freighter ký nonce
→ signedChallenge = wallet.sign(nonce)
✓ Dùng lại y chang waitlist challenge flow
✓ TTL 5 phút, nonce random UUID
✓ Stellar SDK ed25519 verify
BƯỚC 2 — PIN VERIFY + JWT
Frontend gọi POST /admin/auth/login
Body: { walletAddress, signedChallenge, pin }

Backend:
1. Verify ed25519 signature
2. Lookup AdminUser by walletAddress
3. bcrypt.compare(pin, passwordHash)
4. Sign JWT với JWT_ADMIN_SECRET
5. Set httpOnly cookie: tasmil_admin (7d)
✓ JWT_ADMIN_SECRET đã có trong .env
✓ AdminUser model đã có (role, passwordHash)
✓ ADMIN_PASSWORD đã có → dùng làm PIN seed

Admin Bootstrap (Prisma Seed)

Env vars cần thêm:
ADMIN_WALLET_ADDRESS=G... (Stellar public key của admin)
RESEND_API_KEY=re_... (cần thêm)
Seed upsert AdminUser:
walletAddress = ADMIN_WALLET_ADDRESS
passwordHash = bcrypt(ADMIN_PASSWORD)
role = SUPER_ADMIN
SUPER_ADMIN tạo thêm admin khác qua:
POST /admin/users → { walletAddress, pin, role }

Middleware Guard Logic

if pathname.startsWith('/admin') {
if !tasmil_admin cookie → redirect /admin/login
} else if (WAITLIST_MODE && !tasmil_access cookie) {
if !pathname.startsWith('/waitlist') →
redirect /waitlist
} else → next()

// Public routes không bị chặn: /waitlist/*, /admin/login, /api/*
