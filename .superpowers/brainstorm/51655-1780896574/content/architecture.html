Design Section 1: Architecture Overview

Waitlist + Admin Dashboard — Approach A (Minimal, build only what's missing)

System Flow

── USER ENTRY POINT ──────────────────────────────────────
Browser → tasmil-finance.xyz/*
↓ Next.js Middleware
├─ WAITLIST_MODE=true + no valid access token?
→ redirect /waitlist (3-step flow: wallet → email → status)
├─ has valid access code cookie?
→ bypass → /app/* (normal app)
└─ route starts with /admin?
→ check admin JWT cookie → /admin/dashboard
── WAITLIST FLOW (already exists, minor updates) ─────────
Screen 1: Connect Stellar wallet → sign challenge → register
Screen 2: Enter email (optional)
Screen 3: Waitlist status + referral code + queue rank
↳ NEW: "Enter Access Code" field → validate → set cookie → enter app
── ADMIN FLOW (new) ───────────────────────────────────────
/admin/login
1. Connect Stellar wallet → sign challenge
2. Enter PIN/Password → POST /api/admin/auth/login
3. Backend: verify wallet in AdminUser table + bcrypt PIN
4. Return JWT_ADMIN_SECRET signed token → httpOnly cookie
/admin/dashboard (protected by middleware + JWT guard)
Tabs: Overview · Waitlist Entries · Access Codes · Email Campaigns
── BACKEND NEW ENDPOINTS ─────────────────────────────────
POST /admin/auth/login → wallet + PIN → JWT
GET /admin/dashboard/stats → aggregate counts
GET /admin/waitlist/entries → paginated list + filters
POST /admin/access-codes/individual → code for 1 user
POST /admin/access-codes/shared → shared code (N uses)
POST /admin/access-codes/batch → bulk individual codes
POST /admin/access-codes/send-email → send via Resend
GET /admin/access-codes → list all codes
PATCH /admin/access-codes/:id/revoke → revoke code
POST /waitlist/redeem → validate code → set session

Phần nào build mới vs giữ nguyên?

✅ Giữ nguyên

🔨 Build mới

• AdminModule backend (auth + CRUD endpoints)
• ResendService (email delivery)
• Screen 3: thêm "Enter Access Code" field
