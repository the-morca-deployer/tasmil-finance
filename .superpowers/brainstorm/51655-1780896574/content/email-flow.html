Error cases:
• Code không tồn tại → 404
• Code EXHAUSTED (hết uses) → 409
• Code REVOKED → 410
• Wallet chưa register waitlist → 403
EmailDispatch tracking:
• Mỗi email gửi → tạo EmailDispatch record
• PENDING → SENT / FAILED
• Resend webhook → update BOUNCED
• Admin thấy failed count trong dashboard
